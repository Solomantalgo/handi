# Haandi digital menu image manifest

Stock photography is illustrative menu imagery, not a photograph of Haandi's prepared dish or beverage. Replace it with Haandi-approved photographs by editing the stable-ID `ITEM_IMAGE_ASSETS` map in `data.js`; components use each record's `image` field. Unresolved records intentionally render neutral image areas. No individual images are shared between menu items.
